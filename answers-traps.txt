1. Which registers contain arguments to functions?

Ans. In RISC-V, registers a0-a7 contain arguments to functions. a0 contains the format string address and a1 contains 12 (result of f(8)+1) and a2 contains 13.



2. Where is the call to function f and g?
   
Ans. The compiler inlined both functions. Function g is at address 0x0-0xc and simply adds 3 to its argument. Function f is at address 0xe-0x1a and also adds 3 to its argument. In main, the compiler computed f(8)+1 at compile time as 12 (0xc), so there are no actual call instructions to f or g.



3. At what address is printf located?
Ans. Looking at the jalr instruction at address 0x30.



4. What value is in register ra after jalr to printf?
Ans. After the jalr instruction at 0x30, the return address stored in ra will be the next instruction, which is at address 0x34 the exit(0) call.



5. Output of the first printf:
Ans. 57616 in hexadecimal = 0xE110 and little-endian 0x00646c72 = bytes: 0x72, 0x6c, 0x64, 0x00 = characters: 'r', 'l', 'd', '\0' so the output is "He110 World".



6. For big-endian:
Ans. To get the same output "World" in big-endian, I would need to be 0x726c6400 and 57616 would not need to change since it's passed by value, not by reference.



7. What prints after 'y='?
Ans. Whatever value happens to be in the a2 register at the time of the call, which will be garbage/uninitialized data, because printf expects two arguments but only one was provided.
